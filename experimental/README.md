# Speech2Text Live

Experimental local GPU dictation with an editable Copy-preview, Alt+Super+Space shortcut, and configurable push-push or push-to-talk trigger. Copy and paste are always explicit; there is no automatic submission or supported direct IBus delivery.

See [PUBLIC-SETUP.md](PUBLIC-SETUP.md) for requirements, setup, safety limitations, and rollback. This isolated extension uses its own UUID and dedicated backend; it does not replace or modify the original extension's source or service.
